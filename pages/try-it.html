Try It

Hands-on exercises with Yale’s AI tools

Pick one or two exercises that fit your work. Each one names the tool to use and the kind of data that’s safe to use with it.

ImportantUse public or made-up data today

These exercises use published papers, public information or made-up data. Don’t use real participant data in a training session.

  • Tobacco and nicotine research
  • Any researcher
  • Teaching and administration

1. Get oriented on a question in Consensus (low risk: public questions only)

Search Consensus for:

Consensus search 
Do restrictions on flavored e-cigarettes reduce vaping among young people?
  • Look at the Consensus Meter. Then filter to systematic reviews and meta-analyses. Does the picture change?
  • Open three of the cited papers. Was each summarized from the full text (checkmark) or only the abstract?
  • Would you cite any of these without reading the paper? Why not?
TipOther questions to try
  • Are nicotine pouches used as a way to quit smoking among adults?
  • Do graphic health warnings on cigarette packs increase quit attempts?
  • Is exposure to e-cigarette content on social media associated with youth vaping?

2. Compare papers in NotebookLM (moderate risk)

Find 3–5 open-access papers on one topic in PubMed Central. Add them to a new NotebookLM notebook, then ask:

Prompt 
Make a table comparing these studies: design, sample size and population, how nicotine product use was measured, and main finding. Cite the source for each cell.

Click two of the citations. Do they point to the right passage?

3. Write analysis code in Clarity or Claude (made-up data)

Prompt 
I have a survey dataset in R with these variables: age (18-29), pouch_use (0/1, past 30 days), cig_use (0/1), flavor (mint, fruit, tobacco, none), sex. Write tidyverse code to (1) make a table of pouch use by flavor and sex, and (2) fit a logistic regression of pouch use on age, sex and cigarette use. Generate a fake dataset of 200 rows so I can test the code first. Explain each step briefly.

Run the code in R or Positron. Does it run? Do the results make sense for the fake data?

4. Get feedback on your writing in Clarity or Claude (your own unpublished text: moderate risk, so Clarity or Claude Enterprise)

Prompt 
Act as an NIH study section reviewer in tobacco regulatory science. Here is a draft Specific Aims paragraph. List its three biggest weaknesses and suggest how to address each. Don't rewrite it.

[paste your paragraph here]

Asking for critique rather than a rewrite keeps the writing yours, which matters under NIH’s rules on AI-developed applications.

1. Consensus: ask a yes/no question from your field (“Does X improve Y in Z?”). Filter to RCTs. Open the top three papers and check each one says what the summary claims.

2. NotebookLM: add 3–5 open-access papers on one topic. Ask for a comparison table of methods and findings, with citations. Check two citations.

3. Clarity:

Prompt 
I'm a [role] at Yale working on [topic]. My main tasks are [list]. Suggest five ways an AI assistant could save me time, and one way it could cause problems.

4. Clarity with web search (any featured agent):

Prompt 
What has NIH said in 2026 about using AI in grant applications? Link to the official notices.

Then open the links. Are they real NIH pages? Do they say what the answer claims?

Educators:

Prompt 
Draft a 50-minute lesson plan on [topic] for [learner group], with learning objectives, one active-learning exercise and a short quiz.

Then ask it to make the exercise harder.

Administrators:

Prompt 
Here's a job description: [paste]. Draft eight behavioral interview questions, each with what a strong answer would include.

Meetings: after your next Zoom meeting, open the AI Companion summary. What did it miss or get wrong?

Reflect

  • Which task saved the most time? Which needed the most checking?
  • Which tool would you use for your next real task, and what data would you put in it?
