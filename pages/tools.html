Yale’s AI Tools

How to get each one, what it costs, what it does, and what data it’s approved for

Last checked: November 18, 2026. Source of truth: Yale’s AI Tools and Resources. Model names change every few months, so this page doesn’t list them; each tool’s Yale page does.

Yale doesn’t currently provide ChatGPT (Edu or Enterprise) or Perplexity. If you use them with a personal account, treat them like any public website: low-risk data only [1]. For a general chatbot under your Yale account, use Clarity instead; it includes OpenAI’s models [3].

Clarity

Yale’s own AI chat platform, free for current students, staff and faculty [3].

  • Sign in: go to clarity-ai.yale.edu and log in with your Yale account.
  • Models: choose an “agent” for a model from OpenAI, Anthropic (Claude) or Google (Gemini). The agents page lists the current ones.
  • Beta agents (through December 2026): newer models from OpenAI, Anthropic and Google to try, labeled Beta in the agent menu. They support low-, moderate- and high-risk data, and the Health beta agents also support ePHI. They’re less tested, may change or be removed, and aren’t available in custom agents. For critical or time-sensitive work, use a featured agent [4].
  • What’s new (October 2026 Agent Portal): image generation, voice conversations, chat search and tags, mobile use, and connections to other tools [5].
  • Web search: built into every featured agent, including the Health agents, since November 18, 2026. The separate Radiate pilot agent is being removed [4]. Yale’s Clarity page approves web search for up to high-risk data, but another line on the same page still says low risk only [3]. Until Yale confirms, keep ePHI and other high-risk details out of questions that send Clarity to the web.
  • Files: upload up to 10 files at a time [3].
  • Custom agents: build your own assistant with standing instructions and reference files, after your use case is approved [6]. Owners can turn on web search under Manage Agents > Tools > Gemini Web Grounding.
  • Data: approved for low, moderate and most high-risk data. Not for NIST 800-171 data. Data under a data use agreement needs checking first. Your data isn’t used to train the models [7].
  • ePHI: only in the Health agents, which you request through ServiceNow [8].
TipIf you used Clarity before October 2026

The interface and the model list changed. Old models such as GPT-4o and Claude 3.5 were replaced, and Clarity can now search the web. Some older Yale pages still describe the previous version [4, 5].

Claude Enterprise

Anthropic’s Claude with a Yale contract, available since September 2026 [9].

  • Get it: faculty and staff request a license through ServiceNow. Students need sponsorship from their school or department.
  • Cost: $20/month (Standard) or $50/month (Premium), charged to a COA. Heavy use beyond the plan is billed separately.
  • Includes: Claude chat, Claude Code and Cowork, on the web, desktop and mobile. A PubMed connector lets Claude search PubMed directly.
  • Data: high risk. A separate HIPAA, zero-data-retention environment is approved for ePHI.
  • Personal Claude accounts using a yale.edu address can no longer sign in with Yale credentials.

WarningYNHHS Copilot is different

If you also have a Yale New Haven Health account, its Copilot is governed by YNHHS rules: PHI is strictly prohibited there [12].

Gemini and NotebookLM

Google’s tools, through your Yale Google (EliApps) account. Faculty, staff and students 18+ [13].

  • Data: moderate risk when signed in with your Yale account. With a personal Google account, low risk only.
  • Gemini can search the web, generate images and run Deep Research (a multi-step web report with sources).
  • NotebookLM answers questions only from the sources you add to a notebook, with citations back to the exact passage. Limits: 50 sources per notebook, 50 questions and 3 audio overviews a day. More on the Literature Tools page.

Zoom AI Companion

Meeting summaries and in-meeting questions, on by default for Yale Zoom accounts. Approved for high-risk data. Third-party note-taking bots are blocked in Yale meetings [14].

GitHub Copilot

AI coding help inside VS Code, Positron and other editors. Staff and faculty, $19/month, moderate risk [15].

Building something bigger

For a custom chatbot, an API for a research pipeline, or AI over a dataset [6, 16, 17]:

  • Clarity custom agents and the Clarity API: submit a use case to AI Platform Services (ai.platforms@yale.edu). Requests involving PHI also go to Health Sciences IT.
  • Direct model access (Portkey, Azure AI, AWS Bedrock): see ai.yale.edu/api. Azure and AWS projects need a Security Planning Assessment for each app.
  • Medium- or high-risk data in a new tool: use the AI request form at yaledata.yale.edu. The AI Review Framework lists who reviews what.
